# Contributing

Use Python 3.14 and the frozen `uv.lock`. GitHub CI performs linting, offline tests,
Chromium checks, PromQL/rule tests, Terraform mock tests and both container architectures.
Include a concise description of the resulting behavior and relevant validation in PRs.

Preserve the read-only APIs, bounded metric labels, nonroot container and utilitarian
Bootstrap 3 interface: traditional forms, compact bordered tables and gray buttons.
Keep monitoring/cloud infrastructure separate from application behavior.

Update lock/configuration files intentionally. Never commit credentials, `.env`, Terraform
state/plans, databases, virtual environments or generated private artifacts. Keep license
and third-party notices. Historical screenshots must remain identified as reference
evidence; a recipient's acceptance results must come from their own verified run.
